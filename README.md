# Habit Flow MVP

React + Vite based habit tracker MVP focused on daily routine tracking.

## Features

- Add habits with repeat days and a color
- Check off today's habits
- See current streak per habit
- See 7-day completion rate per habit
- Persist all data in `localStorage`

## Run

Install dependencies and start the dev server:

```bash
npm install
npm run dev
```

Default Vite server port is `4173`.
